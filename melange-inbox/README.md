# Melange Inbox

손님 DM 스크린샷을 끌어다 놓으면 Claude가 대화를 읽고 **한국어 번역 · 요약 · 예약 정보 · 손님 질문 · 할 일 · 답장 초안**까지 정리해 주는 단일 파일 웹앱.
`melange-tattoo/` 홈페이지와는 별개의 도구이며, 빌드 도구·프레임워크·서버 없이 동작한다.

## 기능

- 드래그 앤 드롭 / 붙여넣기(Ctrl·⌘+V) / 파일 선택으로 스크린샷 추가. 여러 장을 한 번에 넣으면 하나의 대화로 묶어 읽는다 (옵션으로 각각 분석).
- 인스타그램 DM, 왓츠앱, 카카오톡, 라인, 이메일, 문자 화면 인식. 손님 / 나 구분, 원문 + 한국어 번역 대화 재구성.
- 대화 전체 흐름 요약 + 지금 상태(누구 차례인지), **진행 단계**(문의 → 상담 중 → 일정 조율 → 예약금 대기 → 예약 확정 → 시술 완료 / 미성사 / 취소), 의도, 긴급도. 목록에서 단계 칩으로 바로 보이고 `예약 확정` / `미성사` 필터가 있다.
- 예약 정보는 항상 **최신 상태** 기준(디자인·부위·크기·스타일·일정·지역·예산·레퍼런스·연락처/나이). 대화 중 바뀐 내용은 `이전 → 현재`로 따로 정리하고, 확정된 것과 아직 미정인 것을 나눠 보여준다.
- 같은 손님의 이어지는 스크린샷을 나중에 넣으면 기존 대화에 이어 붙인다: 핸들(@id)이 같으면 자동으로, 이름만 같으면 물어보고, 이름을 못 읽으면 붙이지 않는다 (`다른 대화에 붙이기`로 직접 고를 수도 있고, 토스트의 `따로 두기`로 취소). 열려 있는 대화 화면에 바로 끌어다 놓거나 `스크린샷 추가` 버튼으로도 이어 붙일 수 있다.
- 이어 붙일 때는 새 스크린샷만 읽고 앞부분은 이미 읽어 둔 요약(대화·정보·변경·확정·미정)을 텍스트로 넘긴다. 한 번에 보낼 수 있는 이미지 수를 넘기는 큰 묶음은 나눠 읽으며 요약을 이어 넘긴다. `다시 분석`은 전체를 처음부터 다시 읽는다.
- 오늘 날짜와 캡처 날짜를 함께 넘겨서 `(화)`, `어제` 같은 상대 날짜를 해석하고, 대화 메모에 적은 내용(예: 입금 확인함)은 다음 분석과 답장에 사실로 반영한다.
- 손님 언어로 된 답장 초안 + 한국어 확인본. 내가 쓴 한국어 답장을 손님 언어로 번역 + 역번역 확인.
- **첫 문의 안내 문구**: 디자인·크기(cm)·부위·도시·날짜가 없는 첫 문의에는 설정의 예약 절차 안내 문구(기본값은 실제 보내던 5가지 요청)를 바탕으로 답장 초안을 만든다.
- **예약 상세 안내 양식**: 설정에 내가 보내는 안내문을 그대로 붙여 넣고 `{날짜}` `{예약금}`처럼 자리를 표시하면, 대화에서 값을 찾아 채운 안내문을 손님 언어로 만들어 준다. 못 채운 항목은 `[확인 필요]`로 남기고 따로 알려준다. 예약 확정 단계에 이른 대화는 답장 초안도 이 양식을 따른다.
- 폰: 탭해서 사진 앱에서 스크린샷 선택, `공유` 버튼으로 인스타그램 등에 바로 보내기. 안드로이드에서 홈 화면에 설치하면 스크린샷을 앱으로 `공유`해 바로 넣을 수 있다 (Web Share Target).
- 미처리 / 급함 / 완료 필터, 검색, 메모, 처리 완료 표시, Markdown 내보내기.
- 데이터는 브라우저에만 저장 (localStorage + IndexedDB). 서버 없음.

## 실행

두 가지 연결 방식이 있고, 페이지가 자동으로 고른다.

1. **claude.ai 아티팩트로 게시** — 로그인된 계정의 Claude가 답하므로 API 키가 필요 없다. (`capabilities: {sample: {}, downloads: true}` 로 게시)
2. **직접 호스팅 (Netlify, 로컬 등)** — 설정에서 Anthropic API 키를 넣으면 브라우저에서 Anthropic API로 직접 호출한다. 키는 이 브라우저의 localStorage에만 저장된다.

> 폰의 claude.ai(앱·모바일 웹)에서 연 아티팩트는 아직 Claude에 이미지를 보내지 못한다. 폰에서 쓰려면 아래처럼 직접 호스팅하고 API 키를 넣는다. PC 브라우저의 claude.ai에서는 아티팩트 그대로 쓴다.

### 폰에서 쓰기 (Netlify 직접 호스팅)

1. [Netlify](https://app.netlify.com) → **Add new site → Import an existing project** → 이 저장소 선택.
2. **Base directory** `melange-inbox`, **Publish directory** `melange-inbox` (또는 `.`), Build command 비움. `melange-inbox/netlify.toml`이 헤더를 잡아 준다.
3. 배포된 주소를 폰 브라우저로 열고 **설정 → Anthropic API 키** 입력 (console.anthropic.com 에서 발급, 사용량만큼 과금). 키는 그 폰의 브라우저에만 저장된다.
4. **홈 화면에 추가**하면 앱처럼 열린다. 안드로이드는 스크린샷을 이 앱으로 바로 `공유`할 수 있고, 아이폰은 앱 안의 `스크린샷 추가`로 사진을 고른다.

```bash
python3 -m http.server 8010 -d melange-inbox
# → http://localhost:8010
```

## 모델

기본 `claude-opus-5`, 정밀도 `high` (정확한 정리가 우선). 설정에서 Sonnet 5 / Haiku 4.5로 바꿀 수 있다.
직접 호출 시 서버 측 refusal fallback(`fallbacks: "default"`)을 켜 두어, 기본 모델이 거절하면 같은 요청을 대체 모델이 이어받는다.
