# 동작 버튼

Source: https://developer.apple.com/kr/design/human-interface-guidelines/action-button

> 동작 버튼을 사용하면 지원되는 iPhone 및 Apple Watch 모델에서 사람들이 자주 사용하는 기능에 빠르게 접근할 수 있습니다.

![Apple Watch의 동작 버튼을 가리키는 화살표 모습의 스케치가 있으며, 동작 실행을 나타냄. 이미지에 직사각형 및 원형 그리드 선이 겹쳐져 있고, 여섯 가지 색상으로 된 기존 Apple 로고의 보라색을 은은하게 반영하는 보라색 색조가 적용됨.](https://developer.apple.com/images/com.apple.HIG/inputs-action-button-intro@2x.png)

지원되는 기기에서 사람들은 동작 버튼을 사용하여 [앱 단축어](https://developer.apple.com/kr/design/human-interface-guidelines/app-shortcuts)를 실행하거나, 손전등을 켜거나 끄는 것과 같은 시스템 제공 기능에 접근할 수 있습니다. Apple Watch Ultra의 경우 동작 버튼은 운동 및 다이빙과 같은 활동 관련 동작을 지원합니다.

사람들은 기기를 설정할 때 동작 버튼의 기능을 선택하며, 나중에 설정에서 이 선택을 변경할 수 있습니다. 동작 버튼에 앱 단축어를 연결하고 버튼을 누르면 음성으로 Siri를 사용하거나 Spotlight에서 탭하는 것과 유사하게 앱 단축어가 실행됩니다.

앱 또는 게임을 디자인할 때, 사람들이 자주 사용하는 기능에 빠르게 접근할 수 있는 다른 방법을 제공하는 것이 동작 버튼의 역할이라고 생각하시면 됩니다.

## 모범 사례

**앱의 필수적인 기능들로 동작 버튼을 지원하십시오.** 예를 들어, 요리 앱에 달걀 타이머가 포함된 경우 사람들은 동작 버튼을 눌러 ‘달걀 타이머 시작’ 동작을 실행하려고 할 것입니다. 앱을 여는 앱 단축어를 제공할 필요는 없습니다. 시스템에서 이미 해당 기능을 제공하기 때문입니다. 사람들은 앱 아이콘, 위젯 및 Apple Watch 컴플리케이션과 같은 다른 방법을 통해 빠르게 앱을 열 수 있습니다. 추가 지침을 보려면 [앱 단축어](https://developer.apple.com/kr/design/human-interface-guidelines/app-shortcuts)의 내용을 참조하십시오.

**지원하는 각 동작에 대해 해당 동작을 간결하게 설명하는 짧은 레이블을 작성하십시오.** 사람들은 동작 버튼의 작동 방식을 구성하기 위해 설정을 방문할 때 레이블을 보게 됩니다. 동사로 시작하고 현재형을 사용하며 관사 및 전치사를 제외하는 [title-style capitalization](https://support.apple.com/guide/applestyleguide/c-apsgb744e4a3/web#apdca93e113f1d64)(제목식 대문자 표기법)을 사용하여 레이블을 생성하십시오. 레이블의 길이는 가능한 한 짧게(최대 세 단어) 하십시오. 예를 들어, ‘Started Race’ 또는 ‘Start the Race’ 대신에 ‘Start Race’를 사용하십시오.

**가급적 시스템에서 동작 버튼으로 앱을 사용하는 방법을 사람들에게 표시하도록 하십시오.** 동작 버튼을 지원하면 시스템은 자동으로 사람들이 앱 기능 중 하나를 실행할 수 있게 구성하도록 돕습니다. 설정에서 동작 버튼에 대해 제공하는 지침 또는 시스템이 제공하는 기타 사용 팁의 내용과 겹치는 콘텐츠를 생성하지 마십시오.

## 플랫폼 고려 사항

*iPadOS, macOS, tvOS 또는 visionOS에서는 지원되지 않습니다.*

### iOS

**사람들이 현재 작업 위치를 떠나지 않고 동작을 사용할 수 있도록 하십시오.** 가능한 경우, 앱을 열지 않고도 기능을 제공하도록 [실시간 현황](https://developer.apple.com/kr/design/human-interface-guidelines/live-activities) 및 사용자 설정 스니펫과 같은 가벼운 멀티태스킹 기능을 활용하십시오. 예를 들어, ‘타이머 설정’ 동작은 시계 앱을 실행하는 것이 아니라 타이머 시간을 설정하도록 사람들에게 물어본 다음 카운트다운이 표시되는 실시간 현황을 실행합니다.

### watchOS

watchOS에서는 동작 버튼을 한 번 눌러 경유지를 추가하거나, 다이빙을 시작하거나, 특정 운동을 시작하도록 지정할 수 있습니다. 버튼을 한 번 누르는 것 말고도, 동작 버튼은 구간 표시 또는 다중 운동 중 다음 모달 형식으로 전환하는 것과 같은 부가적인 동작을 지원합니다.

**사람들이 선택한 기본 동작을 지원하거나 진행시키는 부가적인 기능을 제공하도록 고려하십시오.** 대부분의 경우 사람들은 화면을 보지 않고 동작 버튼을 사용하므로 후속 버튼 누르기는 첫 번째 버튼 누르기와 논리적으로 이어지면서 현재 맥락에도 적합해야 합니다. 앱에서 운동 또는 다이빙 동작을 지원한다면 사람들이 쉽게 배우고 기억할 수 있는 간단하고 직관적인 부가 기능을 디자인하는 것을 고려하십시오. 두 개 이상의 부가 기능을 제공하려는 경우, 사람들의 인지적 부하가 높아져 앱 사용이 어렵게 느껴질 수 있으므로 신중히 고민하여 결정하십시오.

**후속 버튼 누르기는 기능을 중단 또는 종료하는 것이 아니라 부가 기능을 지원하는 데 사용하십시오.** 현재 기능을 일시 정지하는 것이 아니라 사람들이 주요 작업을 중단하도록 허용해야 하는 경우, 이를 버튼 누르기로 지원하는 대신 인터페이스에서 해당 옵션을 제공하십시오.

**사람들이 동작 버튼과 측면 버튼을 함께 누르면 현재 기능을 일시 정지하십시오.** 다이빙 앱의 경우는 예외입니다. 다이빙 기능을 일시 중지하면 수심을 더 이상 파악하지 못하거나 얼마나 오래 물속에 있었는지 알지 못하므로 다이버에게 위험이 발생할 수 있습니다. 현재 기능을 일시 정지하는 것이 부정적 경험으로 이어지는 것이 아니라면, 두 버튼을 동시에 눌러 현재 활동을 일시 정지할 수 있도록 지원하여 사람들의 기대를 충족시켜 주십시오.
