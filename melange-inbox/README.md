# Melange Inbox

손님 DM 스크린샷을 끌어다 놓으면 Claude가 대화를 읽고 **한국어 번역 · 요약 · 예약 정보 · 손님 질문 · 할 일 · 답장 초안**까지 정리해 주는 단일 파일 웹앱.
`melange-tattoo/` 홈페이지와는 별개의 도구이며, 빌드 도구·프레임워크·서버 없이 동작한다.

## 기능

- 드래그 앤 드롭 / 붙여넣기(Ctrl·⌘+V) / 파일 선택으로 스크린샷 추가. 여러 장을 한 번에 넣으면 하나의 대화로 묶어 읽는다 (옵션으로 각각 분석).
- 인스타그램 DM, 왓츠앱, 카카오톡, 라인, 이메일, 문자 화면 인식. 손님 / 나 구분, 원문 + 한국어 번역 대화 재구성.
- 대화 전체 흐름 요약 + 지금 상태(누구 차례인지), 의도(예약 문의·견적·일정 변경·취소·디자인 상담·애프터케어 등), 긴급도.
- 예약 정보는 항상 **최신 상태** 기준(디자인·부위·크기·스타일·일정·지역·예산·레퍼런스). 대화 중 바뀐 내용은 `이전 → 현재`로 따로 정리하고, 확정된 것과 아직 미정인 것을 나눠 보여준다.
- 같은 손님(같은 플랫폼 + 이름)의 이어지는 스크린샷을 나중에 넣으면 기존 대화에 자동으로 이어 붙이고 전체를 다시 읽어 정리한다 (토스트의 `따로 두기`로 취소). 열려 있는 대화 화면에 바로 끌어다 놓거나 `스크린샷 추가` 버튼으로도 이어 붙일 수 있다.
- 한 번에 보낼 수 있는 이미지 수를 넘기면 최신 스크린샷만 보내고 앞부분은 이미 읽어 둔 대화 텍스트로 전달한다.
- 손님 언어로 된 답장 초안 + 한국어 확인본. 내가 쓴 한국어 답장을 손님 언어로 번역 + 역번역 확인.
- 미처리 / 급함 / 완료 필터, 검색, 메모, 처리 완료 표시, Markdown 내보내기.
- 데이터는 브라우저에만 저장 (localStorage + IndexedDB). 서버 없음.

## 실행

두 가지 연결 방식이 있고, 페이지가 자동으로 고른다.

1. **claude.ai 아티팩트로 게시** — 로그인된 계정의 Claude가 답하므로 API 키가 필요 없다. (`capabilities: {sample: {}, downloads: true}` 로 게시)
2. **직접 호스팅 (Netlify, 로컬 등)** — 설정에서 Anthropic API 키를 넣으면 브라우저에서 Anthropic API로 직접 호출한다. 키는 이 브라우저의 localStorage에만 저장된다.

```bash
python3 -m http.server 8010 -d melange-inbox
# → http://localhost:8010
```

## 모델

기본 `claude-opus-5`, 정밀도 `high` (정확한 정리가 우선). 설정에서 Sonnet 5 / Haiku 4.5로 바꿀 수 있다.
직접 호출 시 서버 측 refusal fallback(`fallbacks: "default"`)을 켜 두어, 기본 모델이 거절하면 같은 요청을 대체 모델이 이어받는다.
