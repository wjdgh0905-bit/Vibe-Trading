# 숨결 화분

창가에 놓인 작은 식물 하나가 숨결에 맞춰 천천히 자라는 힐링 키우기예요.
할 일은 하나뿐이에요. 손가락을 꾹 누르고 한 번의 느린 숨만큼 물을 주는 것.
잃을 것도, 서두를 일도, 놓칠 것도 없어요.

## 열어 보는 법

- `index.html`을 브라우저에서 바로 열어도 되고,
- 폴더를 정적 서버로 띄워도 돼요. 예: `npx serve .` 또는 `python3 -m http.server`
- 모바일 Safari 16 이상, Chrome 최신 버전에서 동작해요. 세로 화면 기준으로 만들었어요.

## 홈 화면에 추가하기

- **iOS Safari**: 아래 공유 버튼 → `홈 화면에 추가`
- **Android Chrome**: 브라우저 메뉴(⋮) → `홈 화면에 추가`

홈 화면에 두면 기록이 더 안전하게 남아요. (브라우저가 저장 공간을 정리할 가능성이 낮아져요.)
서버로 띄운 경우 `sw.js`가 파일을 캐시해서 오프라인에서도 열려요.

## 기술 메모

- 빌드 없음, 서버 없음, 외부 라이브러리 없음. HTML / CSS / 순수 JS 파일 몇 개가 전부예요.
- 모든 기록은 브라우저 `localStorage`(`sumgyeol.v1`)에만 저장돼요. 계정도, 전송도 없어요.
- 설정 → `기록 옮기기`에서 기록을 글자로 복사해 다른 기기로 옮길 수 있어요.
- 소리는 WebAudio로 즉석에서 만들어요(오디오 파일 없음). 설정에서 켜기 전까지는 완전히 조용해요.
- 식물은 SVG로 그리고, 움직임은 CSS 애니메이션으로만 처리해요.

파일 구성

```
index.html            화면 구조
style.css             스타일, 애니메이션
plants.js             식물 SVG 생성기
whispers.js           식물이 들려주는 말
audio.js              소리
app.js                상태, 저장, 상호작용
manifest.webmanifest  홈 화면 앱 정보
sw.js                 캐시 서비스 워커
icon.svg / icon-*.png 아이콘
```
