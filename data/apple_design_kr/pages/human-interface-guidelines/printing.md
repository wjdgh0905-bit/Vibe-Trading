# 프린트

Source: https://developer.apple.com/kr/design/human-interface-guidelines/printing

> iOS, iPadOS, macOS 또는 visionOS 앱은 적합한 경우 시스템 제공 프린트 기능을 통합하여, 필요할 때 사용자 설정 프린터 및 문서별 옵션을 제공할 수 있습니다.

![프린터 모양의 스케치가 있으며, 프린트를 나타냄. 이미지에 직사각형 및 원형 그리드 선이 겹쳐져 있고, 여섯 가지 색상으로 된 기존 Apple 로고의 주황색을 은은하게 반영하는 주황색 색조가 적용됨.](https://developer.apple.com/images/com.apple.HIG/patterns-printing-intro@2x.png)

## 모범 사례

**프린트를 쉽게 찾을 수 있게 만드십시오.** 프린트 동작을 표준 시스템 위치에 배치하여 사람들이 쉽게 찾을 수 있게 하십시오. 예를 들어, macOS 앱의 파일 메뉴에 프린트 항목을 포함하거나, iOS 또는 iPadOS 앱에서 [동작 시트](https://developer.apple.com/kr/design/human-interface-guidelines/action-sheets)를 여는 도구 막대 버튼을 추가하십시오. macOS 앱에 도구 막대가 있다면 여기에도 프린트 버튼을 넣을 수 있지만, 이 경우 사람들이 도구 막대를 사용자화할 때 추가할 수 있는 선택 사항 버튼으로 만드는 것을 고려하십시오.

**가능한 경우에만 프린트 옵션을 표시하십시오.** 화면에 프린트할 항목이 없거나 사용할 수 있는 프린터가 없다면, macOS 앱의 파일 메뉴에서 프린트 항목을 흐리게 표시하고 iOS 또는 iPadOS 앱의 동작 시트에서 프린트 동작을 제거하십시오. 사용자 설정 프린트 버튼을 구현하는 경우, 프린트가 불가능할 때 버튼을 흐리게 표시하거나 가리십시오.

**관련된 프린트 옵션을 표시하십시오.** 페이지 범위 선택, 여러 장 프린트 또는 양면 프린트와 같은 옵션을 제공하는 것이 적합하고 프린터에서 옵션을 지원한다면 시스템 제공 보기를 사용하여 해당 옵션을 표시하십시오.

## 플랫폼 고려 사항

*iOS, iPadOS 또는 visionOS에 대한 추가 고려 사항은 없습니다. tvOS 또는 watchOS에서는 지원되지 않습니다.*

### macOS

**macOS 앱이 시스템에서 제공하지 않는 앱 특유의 프린트 옵션을 제공하는 경우, 프린트 패널에 사용자 설정 카테고리를 생성하는 것을 고려하십시오.** 기본적으로 프린트 패널은 레이아웃, 용지 프린트 방식, 미디어 및 품질과 같은 여러 설정 카테고리를 제공합니다. 사용자 설정 카테고리에 앱 이름과 같은 고유한 이름을 지정하고, 사람들이 앱에서 탁월한 프린트 경험을 할 수 있도록 지원하는 옵션을 포함하십시오. 예를 들어, Keynote는 발표자 메모, 슬라이드 배경 및 건너뛴 슬라이드를 프린트하는 기능과 같은 프레젠테이션 특유의 옵션을 제공합니다.

**앱에서 문서별 페이지 설정을 지원하는 경우, 페이지 설정 대화상자를 표시하는 것을 고려하십시오.** *페이지 설정 대화상자*는 특정 문서를 프린트하는 데 적용되는 페이지 크기, 방향 및 크기 조절에 대한 설정(자주 변경되지는 않음)을 포함합니다. 앱에 적합한 경우, 이미 시스템에서 제공하는 기능을 구현하지 마십시오. 예를 들어, 페이지 방향을 변경하거나 역순으로 프린트하는 옵션은 시스템에 구현되어 있기 때문에 포함할 필요가 없습니다.

**옵션 간의 상호 의존이 명확하도록 하십시오.** 예를 들어, 양면 프린트를 사용할 수 있을 경우 투명 용지에 프린트하는 옵션은 사용이 불가능해야 합니다.

**자주 사용하는 기능과 고급 기능을 분리하십시오.** 펼침 제어기를 사용하여 필요하기 전에는 고급 옵션을 가리는 것을 고려하십시오. 고급 옵션은 *고급 옵션*이라고 레이블을 지정하십시오.

**사람들이 설정의 효과를 미리 볼 수 있도록 허용하는 것을 고려하십시오.** 예를 들어, 색조 조절 변경에 따른 효과를 표시하기 위해 썸네일 이미지를 업데이트할 수 있습니다.

**수정된 설정을 문서와 함께 저장하는 것을 고려하십시오.** 최소한 문서를 닫기 전까지는 사람들이 다시 프린트할 경우를 대비하여 프린트 설정을 저장해 놓는 것이 좋습니다.
