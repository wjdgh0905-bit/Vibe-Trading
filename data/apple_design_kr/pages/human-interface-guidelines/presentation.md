# 표시 방식

Source: https://developer.apple.com/kr/design/human-interface-guidelines/presentation

- [동작 시트](https://developer.apple.com/kr/design/human-interface-guidelines/action-sheets) — 동작 시트는 사람들이 시작하는 동작과 관련된 선택을 제공하는 모달 뷰입니다.
- [경고](https://developer.apple.com/kr/design/human-interface-guidelines/alerts) — 경고는 사람들에게 곧바로 필요한 중요한 정보를 제공합니다.
- [페이지 제어기](https://developer.apple.com/kr/design/human-interface-guidelines/page-controls) — 페이지 제어기는 표시기 이미지를 한 줄로 표시하고 각 이미지는 페이지를 평면 목록으로 나타냅니다.
- [패널](https://developer.apple.com/kr/design/human-interface-guidelines/panels) — macOS 앱에서 패널은 일반적으로 열려 있는 다른 윈도우에 떠 있는 것처럼 표시되어 활성 윈도우나 현재 선택 항목과 관련된 추가 제어기, 옵션 또는 정보를 제공합니다.
- [팝오버](https://developer.apple.com/kr/design/human-interface-guidelines/popovers) — 팝오버는 사용자가 제어기 또는 상호작용 영역을 클릭하거나 탭할 때 다른 콘텐츠 위에 표시되는 일시적인 보기입니다.
- [스크롤 보기](https://developer.apple.com/kr/design/human-interface-guidelines/scroll-views) — 스크롤 보기를 사용하면 콘텐츠를 수직 또는 수평으로 이동해서 보기의 경계보다 큰 콘텐츠를 볼 수 있습니다.
- [시트](https://developer.apple.com/kr/design/human-interface-guidelines/sheets) — 시트는 현재 맥락과 밀접하게 관련되고 범위가 지정된 작업을 수행할 수 있도록 합니다.
- [윈도우](https://developer.apple.com/kr/design/human-interface-guidelines/windows) — 윈도우는 앱이나 게임의 UI 보기와 구성요소를 표시합니다.
