# 🐾 야생의 전설 (Wild Legend) — 방치형 동물 RPG

의존성 없는 **단일 HTML 파일** 방치형(Idle) RPG. `index.html`을 브라우저로 열면 바로 실행됩니다.

## 핵심 규칙

| 요소 | 내용 |
|---|---|
| 진행 | 존(Zone) → 10웨이브 → 10웨이브마다 **보스**. 존은 **무한**히 이어집니다. |
| 난이도 | 존마다 적 체력이 **×1.42 → ×1.68**로 점점 가파르게 증가 (상한 없음) |
| 보스 | 체력 ×5.5, 보상 ×9, **제한시간 30초**(+강화 시 증가). 실패 시 해당 존 1웨이브로 귀환 |
| 동료 | 12종 동물(햄찌 → 비룡). 레벨당 피해 증가, 10·25·50·100·200… 레벨마다 **피해 ×2** |
| 터치 | 적을 클릭/터치하면 추가 피해. 치명타(×5) 확률 강화 가능 |
| 스킬 | 포효(피해 ×6) / 황금 사냥(보상 ×5) / 시간 압축(30초치 피해 즉발) — 존 5·15·30 해금 |
| 환생 | 존 26+ 도달 시 **야생혼** 획득. 야생혼 1개당 모든 피해 **+9% 복리** → 벽을 넘는 핵심 |
| 오프라인 | 자리를 비운 동안 동료가 자동 사냥(기본 2시간, 강화로 연장) |
| 저장 | `localStorage`에 10초마다 자동 저장 |

## 조작

- 적 클릭/터치 또는 `Space` — 터치 공격
- `1` `2` `3` — 스킬 발동
- `자동 진행` 토글 — 끄면 같은 웨이브에서 파밍

## 밸런스 기준선

시뮬레이션(그리디 구매 AI) 기준: 15분 ≈ 존 12, 1시간 ≈ 존 80대에서 첫 벽 → 환생 1회당 대략 **+12~40존**씩 상승 폭이 가속됩니다.
